HTML Basics

HTML is Markup language that use for structuring information on web pages

HTML support structures like

  • Hading(h1-h6) for title
  • division(div): structuring information and html stuff,
  • article: presenting information with Title and Description
  • section: page practicing
  • paragraph(p): for information
  • image(img): showing image on web page
  • table: presenting table(row, column) based information with there heading
  • link(a): is use for redirect link to the page to navigate another page or content
